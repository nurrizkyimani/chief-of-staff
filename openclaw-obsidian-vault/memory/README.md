# OpenClaw Memory

This folder is the memory-only area for OpenClaw-written notes.

Suggested use:

- `inbox/` for unsorted captured memory
- `daily/` for date-based summaries
- `people/` for durable notes about people
- `projects/` for project context
- `receipts/` for confirmed receipt journal entries
- `decisions/` for important choices and rationale
- `system/` for OpenClaw behavior, prompts, and operating notes

Keep generated notes as Markdown so the vault remains readable in Obsidian and reviewable in Git.
